## 一、先弄清楚 Plus、Pro、Codex 和 Astra

### ChatGPT Plus 是什么？

ChatGPT Plus 是个人付费订阅，官方列出的基础价格为 **20 美元/月**。它提供相对免费版更高的模型和工具使用额度，但不是无限制使用，也**不包含单独计费的 API 调用量**。[官方 Plus 说明](https://help.openai.com/zh-hans-cn/articles/6950777-what-is-chatgpt-plus)。

### Codex Pro 是独立会员吗？

通常不是。用户搜索“Codex Pro 充值”时，可能指的是购买 ChatGPT Pro 来提高 Codex 可用额度。**Codex 是编程产品或使用场景，ChatGPT Pro 是订阅档位**。通过 ChatGPT 账号登录 Codex，会使用相应订阅包含的额度；如果使用自己的 API Key，则按 API 价格另外计费。[官方 Work 与 Codex 说明](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)。

### GPT-6 Astra 是什么？

Astra 是模型名称，不是名为“Astra会员”的单独订阅。符合条件的 Plus 用户可在 Work 和 Codex 中使用 Astra；Chat 中由 Astra 支持的 GPT-6 Pro 则面向符合条件的 Pro、Business 和 Enterprise 用户。是否已开放以及具体额度，以账户中的模型选择器和 Usage 页面为准。[官方 Astra 公告](https://openai.com/index/gpt-6-astra/) · [官方额度说明](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)。

## 二、2026 年套餐怎么选

| 用户需求 | 优先了解 | 关键区别 |
| --- | --- | --- |
| 日常聊天、写文章、图片、资料整理 | ChatGPT Plus | 基础价格 20 美元/月；额度高于免费版，但有限制 |
| 高频复杂开发、重度 Work / Codex | ChatGPT Pro | 有更高档位及不同额度；具体可购档位以结账页为准 |
| 2–200 人团队、集中管理和统一结算 | ChatGPT Business | 标准席位与高级席位可搭配，适合组织使用 |

Business 官方页面显示：**标准席位每人每月 20 美元（年付）或 25 美元（月付）**；**高级席位每人每月 100 美元（年付）或 125 美元（月付）**。这是按席位显示的价格，实际税费和账单以结账页为准。[官方 Business 定价](https://openai.com/zh-Hans-CN/business/pricing/)。

### Pro 200 最新状态：已恢复新购，月费不变

截至 2026 年 10 月 17 日，官方确认 **Pro 200 已恢复新订阅，仍为 200 美元/月**。不符合旧额度保留资格的新订阅适用较低的新额度，不能按原 Pro 20X 的使用经验估算。

**旧额度过渡资格：**在 2026 年 9 月 22 日至 9 月 29 日太平洋时间上午 10 点之间，曾有有效 Pro 200 订阅的用户，在订阅有效期间可保留原额度至 10 月 29 日。此后转为较低的新额度，月费不变；同一账号重新订阅也须符合该资格窗口。

当前 Pro 档位为每月 100、200、500 美元；Pro 500 包含 Ultrafast，保留旧额度的 Pro 200 不会因此获得 Pro 500 功能。

本次核对的官方 Pro 帮助页未列出“Plus 的 10 倍”或“GPT-6 Pro 每周 100 条”等具体数字，因此本文不将其作为已确认限额。请查看账号套餐页、Usage 和官方通知。[官方 Pro 档位与过渡规则](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)。

## 三、GPT-6 Astra 与 Codex 额度怎么算

Codex 额度不是简单的“每月能问多少句”。模型、任务复杂度、推理设置、运行方式都会影响消耗。Work 与 Codex 共享相应套餐的使用额度，可能同时存在五小时和每周两个限制周期。

官方对 **Plus 和 Business 标准席位**提供的本地消息估计范围如下：

| 模型 | 五小时周期内的估计本地消息数 |
| --- | ---: |
| GPT-6 Astra | 5–45 |
| GPT-6.1 Sol | 15–160 |
| GPT-6 Sol | 15–150 |
| GPT-6 Luna | 350–3,000 |

**这些不是保底次数，也不是全部用户的固定上限。** 云端任务、长上下文和高强度推理可能消耗更多额度；周限额也可能先达到。Pro 100、Pro 200、Pro 500 目前在 Work 与 Codex 中没有五小时使用限额，但仍有套餐包含的总额度限制。查看路径为 **Settings → Usage（设置 → 使用情况）**。[官方 Astra 用量说明](https://help.openai.com/zh-hans-cn/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)。

## 四、如何通过官方渠道订阅 ChatGPT Plus

1. 访问 [ChatGPT 官方网站](https://chatgpt.com/)，登录准备长期使用的账号。
2. 打开个人资料菜单，选择升级套餐或查看计划。
3. 核对套餐名称、价格、计费周期、币种和税费。
4. 使用结账页支持的支付方式完成支付，不要把银行卡信息交给聊天中的陌生人。
5. 付款后到 **设置 → 账户**确认订阅状态，并保留收据。

如果页面不提供某个套餐或某种付款方式，不代表更换 IP 就一定能够获得。账户资格、地区支持、付款工具与风险控制都可能影响结账。Plus 目前按月订阅，官方说明不提供 Plus 年度预付套餐。[Plus 官方说明](https://help.openai.com/zh-hans-cn/articles/6950777-what-is-chatgpt-plus)。

## 五、支付宝和微信能直接充值吗

**不要把“第三方商家接受支付宝/微信转账”理解为“OpenAI 官方结账支持支付宝/微信”。** 官方多币种计费帮助文档列出的全球通用方式为信用卡和借记卡，并针对部分地区列出额外本地付款方式；文档没有将中国大陆支付宝或微信支付列为 ChatGPT 网页订阅的普遍直接付款方式。[官方支付方式](https://help.openai.com/zh-hans-cn/articles/10421635-multicurrency-billing)。

如果有人提供“支付宝代充”“微信代开 Plus”，通常是由第三方收款，再通过其掌握的支付渠道处理订阅。付款前应确认商家身份、付款后归属、退款条款、自动续费安排、发票和售后责任。**不建议交出 ChatGPT 密码、邮箱验证码、两步验证代码或长期控制权。** 不要使用来源不明的共享账号。

## 七、企业采购 Business 如何选择席位

对于多人团队，Business 的主要价值不只是“每个人都有 Plus”，而是统一工作空间、管理和计费，以及团队数据治理。官方页面列出的 Business 适用范围为 2–200 名员工，标准与高级席位可以灵活搭配。[官方 Business 定价](https://openai.com/zh-Hans-CN/business/pricing/)。

采购前建议先确认：员工数量、是否需要高频 Codex、是否需要 SSO/MFA、公司数据处理要求、月付或年付预算、发票和税务安排。不要把个人账号转售给多人当作正式企业席位。

## 八、付款失败与会员未到账排查

### 付款被拒绝

核对银行卡是否允许相应国际或线上交易、账单地址是否正确、账户与付款地区是否符合平台要求；若仍失败，查看银行通知及 OpenAI 官方帮助中心。[官方付款问题](https://help.openai.com/zh-hans-cn/articles/7242622)。

### 扣款后仍显示 Free

先核对当前登录邮箱和付款时使用的登录方式。若通过 iOS/Android 订阅，可在应用设置中尝试 **恢复购买**；如仍异常，联系官方支持并提供收据或卡片后四位，切勿向不明客服发送完整卡号或密码。[官方 Plus 排查说明](https://help.openai.com/zh-hans-cn/articles/6950777-what-is-chatgpt-plus)。

### Codex 无法使用 Astra

先检查套餐资格、当前模型是否已开放、客户端是否更新、Usage 页面剩余额度。官方说明 Astra 需要较新的 Codex CLI 版本，相关功能也可能分阶段开放。[官方额度与客户端说明](https://help.openai.com/zh-hans-cn/articles/11481834)。

## 九、常见问题 FAQ

### 1. ChatGPT Plus 一个月多少钱？

官方基础价格为 20 美元/月；最终支付金额以地区、币种、税费和结账页为准。

### 2. Codex Pro 要单独充值吗？

“Codex Pro”通常不是独立的官方套餐名称。Codex 使用量取决于所登录的 ChatGPT 套餐，或单独使用 API Key 时的 API 计费。

### 3. Plus 能用 GPT-6 Astra 吗？

符合条件的 Plus 用户可以在 Work 和 Codex 中使用 Astra；不等于 Plus 自动拥有 Chat 中的 GPT-6 Pro。

### 4. Plus 的 Codex 是无限次数吗？

不是。实际消耗随任务和模型变化，可能受五小时及每周额度限制。

### 5. ChatGPT Pro 200 美元现在能新开吗？

可以。官方已恢复 Pro 200 新订阅，月费仍为 200 美元。不符合过渡资格的新订阅使用较低的新额度；符合条件的账号可在订阅有效期间保留旧额度至 2026 年 10 月 29 日。详细资格见本文第二节及官方 Pro 说明。

### 6. 支付宝能直接在 ChatGPT 官网付款吗？

官方当前支付方式文档没有把支付宝列为 ChatGPT 网页订阅的普遍直接付款方式。应以实际官方结账页为准。

### 7. 微信代充和官方充值有什么区别？

微信向商家付款只是第三方收款方式，不代表 OpenAI 直接接受微信支付，也不意味着第三方获得官方授权。

### 8. 买了 Plus 是否包含 API 额度？

不包含。API 用量按单独的 API 计费规则结算。

### 9. 企业多人使用应该买 Plus 还是 Business？

需要统一管理、工作空间和团队治理时，应重点比较 Business；个人 Plus 不应被当成可任意转售的共享企业席位。

### 10. 付款成功后为什么还是免费版？

先确认登录账号和支付账号一致；移动端可尝试恢复购买，再凭收据联系官方支持。

### 11. Business 标准席位和高级席位有什么区别？

高级席位面向更高强度的使用需求，官方页面列出更高用量和不同的五小时限制规则；应按实际成员工作量配置。

### 12. ChatGPT Plus 可以年付吗？

官方 Plus 帮助文档说明目前不支持 Plus 年度结算或预付多月费用。
